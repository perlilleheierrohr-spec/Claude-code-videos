# Assets

Save the app icon here as **`icon.png`** (1024×1024, no transparency).

`app.json` points `icon`, `splash`, the Android adaptive icon, and the web
favicon at `./assets/icon.png`. Once `icon.png` is in this folder, everything
picks it up automatically — no further config needed.

Optional: for a dedicated splash graphic, add `splash.png` and update the
`splash.image` key in `app.json`.
