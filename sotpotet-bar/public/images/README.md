# Bilder

Legg de seks utklippede PNG-ene (gjennomsiktig bakgrunn) rett i denne mappa,
med nøyaktig disse filnavnene:

| Fil               | Innhold                                  |
| ----------------- | ---------------------------------------- |
| `base.png`        | Søtpotetmos i svart skål (bunnlag)       |
| `chicken.png`     | Kyllingfilet                             |
| `avocado.png`     | Avokadobiter                             |
| `mozzarella.png`  | Revet mozzarella                         |
| `tomato.png`      | Tomatterninger                           |
| `cucumber.png`    | Agurkterninger                           |

Salt har ikke noe bilde — det vises kun som tekst i ingredienslista.

Mangler en fil, hopper forhåndsvisningen bare over det laget i stedet for å
vise et ødelagt bilde.
